# أسواق رحمة — نظام المنتجات والطلبات

موقع PWA (يشتغل على الكمبيوتر والهاتف، ويفتح بلا إنترنت). المنتجات تُقرأ من Google Sheets، وكل عامل يدخل باسم مستخدم وكلمة مرور تحددها أنت داخل Apps Script.

## الملفات
- `index.html` `style.css` `responsive.css` — الواجهة
- `app.js` `database.js` `sync.js` `orders.js` `pdf.js` — المنطق (IndexedDB، المزامنة، الطلبيات، PDF)
- `config.js` — **الإعدادات (هنا تضع رابط Apps Script)**
- `manifest.json` `service-worker.js` — التثبيت والعمل بلا إنترنت
- `apps-script/Code.gs` — الكود الذي تضعه في Google Apps Script
- `assets/images/` — الصور (انظر الأسفل)

## الخطوة 1: جدول المنتجات (Google Sheets)
الصف الأول عناوين الأعمدة بهذا الشكل (الترتيب غير مهم):
`الكود` | `الاسم` | `الكاتيقوري` | `ملاحظة`

الجدول يبقى **خاص** (لا تنشره على الويب).

## الخطوة 2: Apps Script
1. في الجدول: **Extensions (Extensions) ← Apps Script**.
2. امسح الكود الموجود وانسخ محتوى `apps-script/Code.gs`.
3. في أعلى الملف عدّل:
   - `SHEET_ID`: المعرف من رابط الجدول (الجزء بين `/d/` و `/edit`).
   - `USERS`: اكتب العمال، لكل واحد اسم مستخدم وكلمة مرور واسم يظهر في الطلبية، و`code` اختياري (حرف يضاف لرقم الطلبية).
   ```js
   const USERS = {
     'ahmed':  { password: 'كلمة_سر_قوية', name: 'أحمد',  code: 'A' },
     'karim':  { password: 'كلمة_سر_أخرى', name: 'كريم', code: 'K' }
   };
   ```
4. اختر الدالة `testSheet` واضغط **Run** (وافق على الصلاحيات). يجب أن يظهر عدد المنتجات.
5. **Deploy ← New deployment ← Web app**: Execute as: **Me**، Who has access: **Anyone**. انسخ رابط `/exec`.
6. ضع الرابط في `config.js` مكان `PASTE_APPS_SCRIPT_URL_HERE`.

**تغيير كلمة مرور أو إضافة عامل:** عدّل `USERS` ثم **Deploy ← Manage deployments ← ✏️ ← New version ← Deploy** (الرابط يبقى نفسه). تغيير كلمة المرور يطرد الجلسة القديمة لذلك العامل تلقائياً.
**منتج جديد:** أضفه في الجدول فقط؛ يظهر عند العمال في المزامنة التالية (كل 5 دقائق أو زر «مزامنة الآن»).

## الخطوة 3: النشر على GitHub Pages
ارفع كل محتوى المجلد (ما عدا `apps-script` اختيارياً) إلى مستودع GitHub ثم: Settings ← Pages ← Branch `main` / root. افتح الرابط من الهاتف ← «إضافة إلى الشاشة الرئيسية».

## الصور
الشعار والأيقونات موجودة. ما زال ينقص (الموقع يعمل بدونهما بمكان مؤقت) — ضعهما بنفس الاسم:
- `assets/images/hero-banner.png` — بانر الصفحة الرئيسية
- `assets/images/login-background.png` — خلفية صفحة الدخول

لتغيير الشعار: استبدل `logo.png` و`app-icon-192.png` و`app-icon-512.png` بنفس الأسماء.

## ملاحظات مهمة
- أول دخول يحتاج إنترنت. اترك «تذكرني» مفعلة ليفتح التطبيق لاحقاً بلا إنترنت بآخر نسخة من المنتجات.
- سجل الطلبيات وأرقامها محفوظة **في كل جهاز** (ليست مركزية).
- إرسال WhatsApp: على الهاتف يشارك ملف PDF، وعلى الكمبيوتر يفتح واتساب بنص الطلبية. يمكنك وضع رقم في الإعدادات.
- بعد أي تعديل على الملفات غيّر `VERSION` في `service-worker.js` (مثلاً `rahma-v2`) ليصل التحديث للجميع.
- لا تشارك كلمات المرور في محادثات أو مستودع عام: ضع الكود الذي فيه `USERS` في Apps Script فقط، ولا ترفع `Code.gs` بكلمات المرور الحقيقية إلى GitHub.
